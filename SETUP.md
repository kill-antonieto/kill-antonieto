# Publicar tu perfil de GitHub

GitHub muestra este README en tu perfil solo si el repositorio se llama exactamente igual que tu usuario: `kill-antonieto`.

1. En GitHub, crea un repositorio público llamado `kill-antonieto`.
2. No añadas un README inicial desde GitHub.
3. Sube el archivo `README.md` de esta carpeta a la raíz del repositorio.
4. Visita `https://github.com/kill-antonieto` para comprobarlo.

Cuando publiques `dev-journal`, su enlace del README funcionará automáticamente.

## Actividad que sí aporta valor

Cada semana crea una issue con una meta pequeña, trabaja en una rama y abre un pull request. Ideas: mejorar accesibilidad, añadir una sección, corregir un detalle visual o escribir documentación. Los commits en la rama por defecto y los PRs que hagas en repositorios públicos se reflejan en tu gráfico de contribuciones.
